# CERS JSON Schemas

Machine-readable JSON Schema exports per spec §11.2.

## Required schema files

- case-record.schema.json
- run-record.schema.json
- pack-manifest.schema.json
- finding.schema.json
- ask.schema.json
- output-brief.schema.json
- engineer-review-packet.schema.json

All schemas enforce `additionalProperties: false` per spec §11.3.
